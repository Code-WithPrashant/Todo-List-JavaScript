# 📝 To-Do List App

A simple To-Do List application built using HTML, CSS, and JavaScript.

## Features
- ➕ Add Task
- ✏️ Edit Task
- 🗑️ Delete Task
- ✅ Complete Task
- 💾 Local Storage
- ⌨️ Enter Key Support
- 📱 Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
